# CodeStory Documentation

CodeStory is a Python-based tool for automated codebase analysis, documentation, and semantic search. It ingests source code, builds a rich graph of symbols and documentation, and leverages AI to provide insights and natural language querying. CodeStory integrates a modular ingestion pipeline, a Neo4j graph backend, and Azure OpenAI for advanced code understanding.
